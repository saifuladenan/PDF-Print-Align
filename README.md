#  PDF Print Align (PDF Orientation Adjustment Program for Legacy Industrial Printers)

This program is designed to modify the page orientation of PDF files to ensure compatibility with older industrial printers that may have limitations in handling certain page formats. It provides a simple and efficient solution for users needing to print documents with specific orientation adjustments.

## Key Features:
- **Page Orientation Modification**: Adjust the page orientation of existing PDF files between portrait and landscape.
- **Compatibility for Legacy Printers**: Ensure that PDFs are re-oriented to meet the specific format requirements of older industrial printers.
- **Batch Processing**: Easily process multiple PDFs at once, saving time when handling large document sets.
- **Simple Interface**: Intuitive user interface for quick orientation adjustments without requiring technical knowledge.

## Use Cases:
- Perfect for adjusting PDFs created on modern systems for use with older industrial printing equipment.
- Ideal for industries that still rely on legacy printers but need to adapt to new document formatting practices.
